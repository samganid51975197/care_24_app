# 간병24 통합접수 MVP

병원별 간병24 채널에서 보낸 신청과 환자·보호자 자료를 중앙에서 확인하는 모바일 우선 웹앱입니다.

현재 버전은 화면·업무흐름 검토용입니다. 브라우저 로컬 저장소를 사용하므로 실제 환자 개인정보를 입력하면 안 됩니다. 실제 운영 전에는 인증, 병원별 API 키, 암호화 DB, 접근권한, 감사로그, 개인정보 동의·보유기간·파기 절차를 갖춘 서버 연동이 필요합니다.

웹, Android(갤럭시), iOS(아이폰)에서 하나의 주소로 사용 가능한 PWA입니다. Android Chrome은 설치 안내를 지원하고, iPhone Safari는 공유 → 홈 화면에 추가로 설치합니다. 서비스 워커가 기본 화면을 캐시해 재방문 속도와 제한적인 오프라인 실행을 지원합니다.
