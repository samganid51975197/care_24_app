# 순천향대학교 부속 천안병원 30초 홍보 영상 확인안

## 생성 전 상태

HeyGen 생성 요청 전 검토용 문서다. 이 문서의 모든 항목이 확인되기 전에는 생성하지 않는다.

## 0–15초: 병원 길 안내

- 시작 화면(0–3초): 순천향대학교 부속 천안병원 **공식 로고**와 **건물 외관 이미지**를 함께 표시한다.
- 나레이터: “순천향대학교 부속 천안병원은 충남 천안시 동남구 순천향6길 31에 있습니다.”
- 안내 화면: 지도 앱에서 병원명을 검색해 길 안내를 받는 방법을 보여 준다.
- 병원 예약 안내: 1577-7523.

## 15–30초: 간병 안내

- 나레이터: “병원 동행과 간병 의뢰 신청은 간병24가 돕습니다. 등록 전문간병사 돌봄 안내는 일육공공오하나구칠로 문의하세요.”
- 엔딩 3초 자막: **간병의뢰는 1600-5197**
- 나레이터 전화번호 발음: **일육공공오하나구칠**

## 고정 표현

- 병원명: 순천향대학교 부속 천안병원
- 아바타: 황서윤 · 간병24 목걸이 명찰 · PR-003
- 영상 형태: 길 안내와 간병 안내가 이어지는 한 편의 30초 영상
- 앱 등록 위치: 전국 병원 통합 돌봄 앱의 해당 병원 첫 화면 상단
