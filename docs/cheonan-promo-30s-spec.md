# 순천향대학교 부속 천안병원 30초 홍보 영상 확인안

## 생성 전 상태

HeyGen 생성 요청 전 검토용 문서다. 이 문서의 모든 항목이 확인되기 전에는 생성하지 않는다.

## 최종 30초 구성

| 구간 | 화면 | 나레이터 |
| --- | --- | --- |
| 0–3초 | 순천향대학교 부속 천안병원 공식 로고와 건물 외관 | “순천향대학교 부속 천안병원입니다.” |
| 3–15초 | 지도 앱에서 병원명 검색, 주소와 예약전화 표시 | “충남 천안시 동남구 순천향6길 31에 있습니다. 지도 앱에서 병원명을 검색해 길 안내를 받으세요. 진료 예약은 1577-7523입니다.” |
| 15–27초 | 황경옥 사원증을 단 AI 아바타와 간병24 안내 | “재가 및 병행 동행과 간병 의뢰 신청은 [간병24 공식 로고 이미지]가 돕습니다. 등록 전문간병사 돌봄 안내를 받으세요.” |
| 27–30초 | 엔딩 문의 카드 | “간병 의뢰는 일육공공오하나구칠입니다.” |

## 사원증 확인 기준

- 표기: **사원증**
- 얼굴: 황경옥 AI 아바타 얼굴 — 증명사진처럼 얼굴을 클로즈업하여 또렷하게 표시
- 로고: 간병24 원본 등록상표 로고 이미지
- 이름: 황경옥
- 소속: 홍보개발부
- 사원번호: PD-003
- 형태: 일반 세로 사원증 비율(약 54 × 86mm)

## 고정 표현

- 병원명: 순천향대학교 부속 천안병원
- 영상 형태: 길 안내와 간병 안내가 이어지는 한 편의 30초 영상
- 엔딩 자막: **간병의뢰는 1600-5197**
- 나레이터 전화번호 발음: **일육공공오하나구칠**
- 앱 등록 위치: 전국 병원 통합 돌봄 앱의 해당 병원 첫 화면 상단

## 출처

- 병원명, 주소, 예약전화: https://www.schmc.ac.kr/cheonan/index.do
- 병원 공식 로고와 외관 이미지만 사용한다.



## 브랜드 표기 규칙

- 영상의 화면·대본에서 간병24는 일반 글자 대신 항상 공식 간병24 로고 이미지를 사용한다.
- 로고 이미지에는 등록상표 표기(®)를 함께 쓴다.



- 명찰 얼굴사진: 원형 프레임 안에 얼굴 중심의 증명사진형 클로즈업을 사용하며 전신·상반신은 사용하지 않는다.


## 최종 생성 전 점검

- [ ] 목걸이형 세로 사원증이 자연스러운 크기로 보이는가
- [ ] 사원증 상단에 ‘사원증’이 충분히 크게 표시되는가
- [ ] 원형 얼굴사진이 증명사진형 클로즈업인가
- [ ] 공식 간병24 로고 이미지와 ® 표기가 선명한가
- [ ] 이름 황경옥 · 소속 홍보개발부 · 사원번호 PD-003이 정확히 읽히는가
- [ ] 길 안내 15초와 재가 및 병행 동행·간병 안내 15초가 한 편의 30초 영상으로 연결되는가
- [ ] HeyGen 생성 직전 표시된 실제 크레디트가 승인 범위 내인가


- 엔딩 안내 카드: 첨부된 ‘간병의뢰는 1600-5197’ 이미지 카드를 마지막 3초에 표시한다.
