# HeyGen 영상 제작 필수 확인 기준

## 적용 범위

간병24와 병원 홍보, 교육 영상에 대한 모든 HeyGen 생성 요청에 적용한다.

## 생성 전 필수 확인

크레디트가 차감되는 HeyGen 생성 요청 전에는 다음 여섯 항목을 한 화면에서 실제 영상에 사용할 자료로 확인한다.

1. AI 아바타 명찰의 정확한 간병24 로고와 명찰 형태
2. 병원명과 연락처
3. 길 안내 15초 문구
4. 간병 안내 15초 문구
5. 두 내용이 이어지는 한 편의 30초 구성
6. 엔딩 3초 화면의 문의 문구: **간병의뢰는 1600-5197**

여섯 항목 중 하나라도 실제 자료로 확인되지 않으면 HeyGen 생성 요청을 보내지 않는다.

## 오류 발생 시 처리

- 오류 영상은 공개, 앱 등록, 서버 등록에 사용하지 않는다.
- 추가 생성으로 오류를 덮지 않는다.
- 영상 ID, 생성 시각, 확인된 오류, 크레디트 차감 내역을 기록한다.
- HeyGen Billing 또는 Usage 내역으로 실제 차감량을 확인한 뒤에만 후속 조치를 정한다.
- 환불 또는 크레디트 검토 요청은 근거를 정리한 뒤 사용자 승인 하에 진행한다.
