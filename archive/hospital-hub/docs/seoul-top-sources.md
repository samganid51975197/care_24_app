# 서울탑병원 및 공통 첫 화면

확인일: 2026-09-21

- 서울탑병원: 서울특별시 동대문구 정릉천동로 102 (제기동), 대표전화 02-2088-0580.
- 주소/연락처: 국민건강보험 일산병원 진료협력센터 협력병원 목록 https://www.nhimc.or.kr/ref/board/hospitalBoard1List.do?page=12
- 층별 공간: 2026-05-07 조선대학교 작업치료학과에 게시된 서울탑병원 채용안내. 지하 1층 치료실, 1층 일반병동, 2층 감염관리병동 및 재활치료실, 3층 일반병동 및 재활치료실, 4층 일반병동.
- 층별 출처 https://ot.chosun.ac.kr/ot/3001/subview.do?enc=Zm5jdDF8QEB8JTJGYmJzJTJGb3QlMkYzOTMlMkYyMzEzOTklMkZhcnRjbFZpZXcuZG8lM0Y%3D
- 병원 홈페이지는 확인 당시 도구에서 열리지 않아 현행 공식 평면도를 확인하지 못함. 공개 채용안내의 층별 용도만 사용. 1층 통합간호 예정이라는 표현은 시행 확인 전이므로 운영 기능으로 표시하지 않음.
- 병실 번호/침상 배치는 추정하지 않음. 상황판은 실제 접수의 위치 정보를 표시함.
- 전체 병원은 동일한 첫 화면 컴포넌트를 사용. 층별 자료가 없는 병원에는 분당 병원 구조를 복사하지 않고 등록 의뢰의 위치를 표시함.
- 모든 병원에 지도 검색/길찾기 링크. 확인된 주소가 없으면 지역+병원명으로 검색하도록 표시하며 상세 주소를 추정하지 않음.
