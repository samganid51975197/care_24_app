# 재활치료 독립 화면
홈·공통 메뉴·각 병원 서비스에서 #rehabilitation으로 진입한다. #rehab은 기존 재활병원 찾기이므로 유지한다. 병원별 링크는 ?hospital=기관ID를 전달한다.
환자 재활치료 8개와 뇌신경 재활치료 7개의 상세교육·이전/다음·목록·홈을 제공한다. 접수 양식이나 API를 추가하거나 변경하지 않는다. 기존 care24-brand.webp 이미지와 공통 헤더를 재사용한다.
첨부 이미지는 전체 화면 구성 시안으로 원본 그대로 저장·표시하며, 영상 재생시간·운동 횟수는 실제 영상이나 개별 처방이 아님을 구분한다. 실제 영상은 제공받지 않았으므로 가짜 재생 버튼을 만들지 않는다.
2026-09-21 NHS 침상 운동 및 뇌졸중 재활 자료를 참고한 읽는 교육자료이며 병원별 치료계획을 우선한다.

사용자 위치 수정: 공통/홈/병원 홈 재활 진입 링크 제거. 환자·보호자 의뢰 화면 상단에서만 재활치료(환자) 링크 제공. 일반병원·요양/재활시설 의뢰 모두 적용. 새 탭으로 열어 미제출 의뢰의 입력값을 유지한다.
