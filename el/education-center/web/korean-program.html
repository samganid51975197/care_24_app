과정 목표와 평가

  • 한글과 기초 표현을 진단하고 시작 수준에 맞춰 보완합니다.
  • 정중한 질문·재확인·동의 확인·담당자 보고 표현을 연습합니다.
  • TOPIK II 듣기·읽기·쓰기 문제 형식, 시간 관리와 쓰기 피드백을 익힙니다.
  • 시작 전 진단, 모듈별 과제, 중간 오답 점검, 종합 모의평가로 학습을 확인합니다.

TOPIK II 3급 공식 점수 참고: PBT 총점 300점 중 120~149점, IBT 총점 600점 중 191~290점입니다. 이 수업은 시험 대비 과정이며 급수 취득을 보장하지 않습니다. 국립국제교육원 TOPIK 안내

01 · 인사말과 기본 표현 · 24시간

목표: 한글·받침을 익히고 존댓말로 인사·요청·재질문을 합니다.

한글·소리 진단 6h → 인사·호칭 6h → 듣고 따라 말하기 6h → 역할극·피드백 6h

간병사: 안녕하세요. 저는 린입니다. 동료: 이름을 다시 말씀해 주세요. 간병사: 린입니다. 천천히 말씀해 주시면 좋겠습니다.

과제: 이름·시간을 듣고 메모한 뒤 상대에게 다시 읽어 확인합니다.

수행 확인: 인사·이름·재질문을 상대가 이해할 수 있게 말합니다.
02 · 자기소개와 일과 설명 · 24시간

목표: 이름·출신·실제 경험·학습 목표를 말하고 날짜·요일·근무 시간을 설명합니다.

사람·국적·직업 6h → 시간·요일 6h → 소개문 쓰기 6h → 면담·발표 6h

동료: 어느 나라에서 왔어요? 학습자: 베트남에서 왔어요. 제 이름은 마이예요. 동료: 오늘 교육은 몇 시예요? 학습자: 아홉 시예요.

과제: 사실에 맞춘 4문장 소개문과 1분 발표를 준비합니다.

수행 확인: 실제 경험을 소개하고, 이해하지 못한 질문은 다시 설명해 달라고 요청합니다.
03 · 병원 용어와 지시 이해 · 24시간

목표: 병원 공간·물품·신체·일상지원 어휘를 구분하고 지시의 대상·시간·내용을 확인합니다.

장소·사람·물품 6h → 위치·숫자 듣기 6h → 안내문 읽기 6h → 모의 병동 길 안내·재확인 6h

간병사: 휴게실은 어디에 있습니까? 동료: 간호사실 맞은편입니다. 간병사: 간호사실 맞은편이 맞습니까? 동료: 네, 맞습니다.

과제: 모의 지시에서 ‘누구를 / 언제 / 무엇을’ 기록합니다. 모르는 약·처치 표현은 담당 간호사에게 확인합니다.

수행 확인: 빠진 정보가 있으면 다시 묻고 임의로 행동하지 않습니다.
04 · 환자와의 대화·보고 · 24시간

목표: 요청을 듣고 동의를 확인하며 환자의 말과 관찰 사실을 구분해 보고합니다.

요청·불편함 듣기 6h → 확인·동의 6h → 보고문 쓰기 6h → 환자·간병사·간호사 역할극 6h

환자: 좀 불편해요. 간병사: 어디가 불편하신지 말씀해 주시겠어요? 환자: 등이 불편해요. 간병사: 간호사 선생님께 알려드릴게요.

과제: 시간과 들은 표현을 바꾸지 않고 담당 간호사에게 전달합니다.

수행 확인: 추측이나 진단을 덧붙이지 않고 위험·거부·이상 변화를 보고합니다.
05 · 생활 어휘와 문서 읽기 · 24시간

목표: 한·베 어휘장에 예문을 만들고 생활·기숙사·근무 일정 표현을 읽습니다.

음식·장보기·금액 6h → 교통·길 찾기 6h → 안내문·기록표 6h → 생활 미션·복습 6h

손님: 이 물은 얼마예요? 직원: 한 병에 천 원이에요. 손님: 두 병 주세요. 영수증도 주세요.

과제: 가격표를 읽어 수량·합계를 말하고 근무표의 날짜·시간·장소·준비물을 확인합니다.

수행 확인: 금액·수량을 구분하고 이해하지 못한 안내를 다시 질문합니다.
06 · TOPIK II 3급 대비 · 40시간

목표: 듣기·읽기·쓰기 유형과 시간 관리를 익히고 진단에 따라 보충합니다.

진단·오답 분석 8h → 듣기·읽기 12h → 문장 연결·설명 글쓰기 12h → 모의 연습·종합 피드백 8h

듣기: 상황·화자 관계·핵심 정보 찾기. 읽기: 문장 연결·중심 내용·안내문 파악. 쓰기: 요구 사항에 맞춰 문장 구성, 강사 피드백 후 다시 쓰기.

과제: “한국 생활을 준비하는 나의 학습 계획”을 5~7문장으로 작성합니다.

평가: 오답을 어휘·질문 이해·시간 배분·문장 구성으로 나누고 보충 과제를 정합니다. 모의점수는 공식 급수 판정이 아닙니다.

복습 5분 → 교재 표현·듣기 15분 → 짝 연습 15분 → 생활·병원 상황 과제 15분 → 피드백·과제 10분
