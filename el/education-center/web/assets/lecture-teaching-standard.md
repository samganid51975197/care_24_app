# 전문간병사 강의 영상 제작 기준

교안은 강의의 재료입니다. 화면의 문장과 항목을 그대로 낭독하지 말고, 수강생이 현장에서 판단하고 안전하게 행동할 수 있도록 설명을 보충합니다.

## 각 단원에서 설명할 내용

1. **쉬운 풀이**: 낯선 용어를 일상적인 말로 풀어 설명합니다.
2. **핵심 원리**: 왜 그 관찰이나 안전 절차가 필요한지 설명합니다.
3. **환자별 차이**: 같은 진단이라도 증상·기능·지시가 다를 수 있음을 사례로 보여 줍니다.
4. **현장 적용**: 언제 멈추고, 무엇을 확인하고, 누구에게 어떻게 보고하는지 구체적으로 설명합니다.
5. **오해 바로잡기**: 간병사가 진단·처치·운동 강도·기기 설정을 임의로 결정하지 않도록 업무 경계를 짚습니다.
6. **복습**: 단원 끝에서 핵심 행동과 위험 신호를 짧게 정리합니다.

## 말하기 방식

- 슬라이드 문장을 순서대로 읽지 않고, 강사가 수강생에게 설명하듯 자연스럽게 연결합니다.
- 교안의 사례를 “이 상황에서 무엇을 먼저 확인할까요?”와 같은 질문으로 소개하고, 안전한 대응 이유까지 풀이합니다.
- 실제 환자에게 적용되는 처방이나 기관별 절차를 만들어 내지 않습니다. 개인별 계획과 의료진·재활치료사의 지시를 따릅니다.
- 근거자료의 표현을 확대해 단정하지 않습니다. 새 임상 정보를 보충할 때는 공공기관·전문기관의 최신 자료를 확인하고, 제작 전에 임상·교육 검토를 받습니다.
- HeyGen에는 최종 검토된 강사용 대본을 전달합니다. 영상 생성이 막혀 있어도 원고의 완성 여부와 영상의 생성 여부를 구분해 표시합니다.
