# 전문간병사 교육지원센터 (EL)

16개 질환별·특화 과정의 교육 화면입니다.

- `site/`: 공개 전용 정적 메인 화면. `index.html`과 필요한 정적 파일만 포함합니다.
- `web/`: 원본 작업자료 보관 폴더. 검토되지 않은 접수·시험·관리 기능이 섞여 있어 웹서버 배포 대상으로 사용하지 않습니다.
- 기존 NW 교육 모듈은 수수료·인증서 기능 검토 전까지 EL 공개 화면에 복사하지 않았습니다.

## 공개 범위

교육 과정 개요와 학습용 사례를 제공합니다. 공식 접수, 자격시험, 수료·자격 확인 또는 발급을 처리하지 않습니다. 신청자 명단, 교실 명단, 내부 강의 초안·생성 상태, 관리자/API 페이지 및 재무정보는 `site/`에 포함하지 않았습니다. DB와 로그인을 연결하지 않았습니다.

## 호스팅 상태

독립 HTTPS 도메인과 가비아 경로는 아직 확정되지 않았습니다. 이 변경은 아직 운영 서버에 반영되지 않았으며, 도근 님이 PR 검토 후 주소·경로를 정하고 직접 서버에 저장·배포해야 합니다.
